## Open a transcript for review

When a transcript finishes processing it lands in the **Needs review** group on the Transcripts page. Click **Review** on the row to open the review sheet.

The review sheet has two panels side by side:
- **Speakers** — the speaker rename controls.
- **Transcript** — the full diarized text.

## Rename speakers

The diarization pipeline assigns raw labels — `SPEAKER_00`, `SPEAKER_01`, and so on. The Speakers panel lists each label with a text field where you type the real name.

<Steps>
  <Step title="Identify the speakers">
    Read the first few segments in the Transcript panel to match voices to labels.
  </Step>
  <Step title="Type the names">
    Click into each speaker field in the Speakers panel and type the person's name. The placeholder reads "Type names to replace the raw labels". You can also keep a raw label by choosing "(keep raw label)".
  </Step>
  <Step title="Names update live">
    As you type, every occurrence of that speaker label in the Transcript panel updates in real time.
  </Step>
</Steps>

<Note>
If speaker detection was disabled for this recording, all segments share one label. Type a single name to label the whole transcript ("Speaker detection was disabled for this recording, so all segments share one speaker.").
</Note>

## The transcript panel

The Transcript panel shows every segment with its start and end timestamps and the speaker label. Segments are ordered chronologically.

Scrolling through a long transcript, you can click any segment to jump the audio playback to that point (audio upload only).

## Audio timeline

For transcripts created from uploaded audio files, an audio playback bar appears at the bottom of the review sheet. It shows the waveform or a simple progress track, a play/pause button, and the current playback position. Click anywhere on the timeline to seek.

<Note>
Audio preview is not available for meeting recordings ("Audio preview isn't available for meeting recordings.").
</Note>

## Post-processing results

If post-processing prompts were attached to the job (meeting recordings only), a **Post-processing** section appears below the Transcript panel. Each configured prompt appears as a card:

- **Result text** — the prompt ran and returned output.
- **Re-run** — the prompt ran previously; click to run it again (for example, after renaming speakers).
- **Run** — the prompt has never run (its auto-run was lost); click **Run** to start it now.
- **Running…** — a run is in progress or was claimed within the last 30 minutes.
- **Failed** — the last run produced an error; click **Re-run** to retry.

<Note>
Prompts configured for a job but whose auto-run did not complete appear as **Run** cards so you can start them manually from the review sheet.
</Note>

## Sign off, and publish

Reviewing a transcript and putting it in the knowledge base are two separate
steps. A transcript you have checked is not searchable by agents until you
say so.

**Mark as reviewed** signs the transcript off. Your speaker names and text
corrections are saved, the row takes a **Reviewed** badge, and the transcript
leaves the **Needs review** tab — but it does not enter the knowledge base,
so no agent can search or cite it. The panel says as much: *"Reviewed, not
published."* You can still export a reviewed transcript to Word, which is the
main reason to stop here: confirm a transcript is correct, send it to someone,
and keep it out of search.

**Publish to knowledge base** puts it in. IMP creates an item in the built-in
transcriptions knowledge context, applies the sharing you chose, and the panel
switches to *"In the knowledge base — agents with access can search and cite
this transcript."* You can publish directly from **Needs review** without
marking it reviewed first; that one-step path is unchanged and is still the
common one.

<Warning>
Sharing you set on an unpublished transcript is an **intention**, not access.
Permissions become real when the item is created, so until you publish, a
transcript stays visible only to you however you have set it up.
</Warning>

<Info>
A published transcript is available across IMP. You can pin it to a project's
Files tab or add it to a chat session via the **Add knowledge** menu — see
[Knowledge overview](/building/knowledge/overview) for how knowledge items
work across the platform.
</Info>

Reopening a published transcript lets you correct it again; publishing a
second time updates the existing knowledge item rather than creating a
duplicate.

### Delete a saved entry

To remove a saved transcript from the list, click the trash icon on its row. A confirmation dialog titled **"Delete saved transcription?"** appears. By default it removes only the list entry ("This removes the entry from this page. The saved transcript stays in the knowledge base unless you also select it below."). Check **Also delete the saved transcript from the knowledge base** to remove the knowledge item at the same time. Click **Delete** to confirm.

## Discard a transcript

Click **Discard** in the review sheet to cancel the job. The confirmation dialog warns: "The audio stays in your files; the transcription job will be cancelled." The uploaded audio file is kept in your file storage.
