3## Description
4Generates a structured weekly performance report from the last 7 days
5of activity data. Formats output as an executive-readable Markdown
6document with a headline summary, key metrics table, and action items.
7
8## When to use
9Use this skill when asked to summarize the week, produce a weekly
10digest, or compile a performance overview.
11
12## Output format
13See output-format.md for the required structure. Always include:
14- Executive summary (3–5 sentences)
15- Metrics table (impressions, conversions, cost)
16- Top 3 wins
17- Top 3 risks or blockers
18- Recommended actions
