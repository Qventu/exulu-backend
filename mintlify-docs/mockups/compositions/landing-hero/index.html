We're seeing error 0x4F on an AC-300 controller — what causes it, and how do we clear it?
Tool: search knowledge base · 0.8 s
0x4F on the AC-300 signals a supply-voltage fault on the controller board. Check the 24 V rail and fuse F2 first AC-300_manual.pdf· p. 143, then re-seat the sensor harness on connector X3 before clearing the code wiring_diagram.dwg· sheet 2. Clearance requires a documented visual inspection service_bulletin_04-26.pdf· §2.1.
