What's new in Exulu.

Tools that connect to your accounts, images you art-direct inside the chat, an assistant that knows your preferences, and teams for sharing at scale.

OAuth 2.0 for tools

Connect your tools to Google, Slack, HubSpot — any OAuth provider — with one config property.

Any ExuluTool can now declare an oauth block: authorization and token endpoints, client credentials, scopes. That's the whole integration. When a user runs the tool without a connected account, the agent replies with a connect link; once they've authorized, the tool runs with a valid access token injected as inputs.oauth.accessToken.

Tokens are scoped per tool and per user, stored encrypted, and refreshed automatically when they expire. A single platform-provided /oauth/callback route completes the flow for every tool — PKCE is on by default, and there are no routes or token tables for you to build.

From the SDK
new ExuluTool({
  id: "hubspot_crm",
  name: "HubSpot CRM",
  type: "function",
  oauth: {
    authorizationUrl: "https://app.hubspot.com/oauth/authorize",
    tokenUrl: "https://api.hubapi.com/oauth/v1/token",
    clientId: process.env.HUBSPOT_CLIENT_ID,
    clientSecret: process.env.HUBSPOT_CLIENT_SECRET,
    scopes: ["crm.objects.contacts.read"],
  },
  execute: async (inputs) => {
    const token = inputs.oauth.accessToken; // always valid here
  },
});

In-chat image generation

Generate, refine and pick images — without leaving the chat.

When the assistant calls the image_generation tool, it now opens a widget right in the conversation instead of guessing at a final image. You drive from there: edit the prompt, switch models, set size, quality and count, attach reference images, and apply saved styles.

Attach reference images and the same widget becomes an editor. Selection is explicit — generate as many variations as you like, then pick the ones that work and send them back with Use these. The agent only ever sees your selection, never the rejects.

Personal system prompt

Tell Exulu about yourself once — every conversation remembers.

The new Settings page has a free-form personal prompt: your role, the languages you work in, how long you like answers, anything. When set, it's injected into the system message of every chat you start — on top of whatever agent you're talking to.

It sits between the agent's instructions and the generic context, so shared agents stay shared while your conversations stay yours. Plain text, no length limit, editable any time.

Teams

Group users into teams — then share agents, projects and data team-wide.

Teams are a new organizational layer next to roles: every user can be assigned to one team (Engineering, Marketing, HR — whatever fits), straight from the users table. Super admins manage them from the new Manage teams page.

Sharing gets a matching upgrade: any resource can now use the Shared with Teams visibility mode, granting read or write to whole teams the same way roles work today. Teams carry no permissions of their own — roles keep governing abilities, teams handle who works together and where usage gets attributed.
