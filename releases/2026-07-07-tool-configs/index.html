Your project, inside your coding tools.

Every Exulu project now hands you ready-to-use configs for Cowork, Claude Code, and continue.dev — plus a one-click project ID copy. Connect a tool in seconds, not a doc-hunting session.

One-click tool configs

Point Cowork, Claude Code, and continue.dev at your project's models — no hand-copied URLs, no pasted tokens.

The ⋯ menu on every project now generates tool configs on the spot: Download Cowork config, Download Claude Code config, and Download continue.dev config, alongside a new Copy ID action. Each file arrives with your project's model gateway URL and your access token already filled in — download, drop it into the tool, done.

The Claude Code settings.json goes a step further: it reads the project's live model catalog, defaults to the best available Opus model, and lists every model the project can use. Cowork gets a gateway provider config, and continue.dev gets a YAML with chat, edit, and apply roles wired to the project's OpenAI-compatible endpoint.

Because every tool routes through the project's own gateway, usage is attributed to the project it belongs to — budgets, rate limits, and cost reporting keep working no matter which editor the traffic comes from.

  "model": "claude-opus-4-8",

  },
  "apiKeyHelper": "echo <your-token>"
}
