20 July 8, 2026 Platform Roundup

Vertex billing labels

Your GCP invoice now knows which agent spent what.

Vertex spend used to arrive in Google Cloud Billing as one undifferentiated line. Every Vertex generateContent call now carries up to six billing labels — provider, user, role, project, and agent — visible in Cloud Billing reports (with Google's usual ~24-hour lag). A label failure never breaks a model call, and only opaque IDs leave the box — no emails, no names. Keep in-product tagging for your dashboards; this one is for the bill.
