27 July 8, 2026 Platform Roundup

File sandbox, per agent

File tools only for the agents that need them.

Agent runtime

Sandbox file tools — readFile, writeFile, bash — are now opt-in per agent. One switch in the agent editor's Chat experience section decides whether the agent gets a sandbox at all, so knowledge-only agents stay lean: no shell, no file tools, no spurious shell calls.

The chat composer follows the setting. With the sandbox off, Session files is disabled with the reason shown inline; flip it on for agents that run skills or generate files, and everything lights back up.
