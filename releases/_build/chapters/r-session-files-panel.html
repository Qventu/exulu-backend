06 May 29, 2026 The Spring Drop

Session files panel

Every chat now has its own workspace.

A folder icon in the chat header opens a sidebar listing every file the session has touched — files the agent wrote, files you uploaded, artifacts from tool runs. Click any row to preview text, code, markdown, images, PDFs, and Office documents.

Drop new files into the upload zone and the agent can read them on its next turn — no restart needed. Session files stay private to the session: they never cross into other sessions, projects, or knowledge bases.
