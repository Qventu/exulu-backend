Every file your agent creates —
shareable in two clicks.

Agents build things: HTML pages, reports, spreadsheets, PDFs. Now you can turn any of those files into a shareable link right from the chat — public, password-protected, or scoped to your team.

Shareable Artifact Links

Share any agent-created file in two clicks — with your choice of access control.

A new share icon lives on every file row in the Session Files panel. Click it, pick an access mode, set an expiry, and hit Create link — the URL is copied to your clipboard and the link is live immediately.

The same dialog is available from file references inside chat messages and from inline S3 artifact links that agents paste into their replies. Wherever an artifact surfaces, the share affordance is right there.

Public — anyone with the URL
Password — gated by a secret
Login required — scoped to Exulu users

When the artifact is an HTML file, visiting the link renders it live in the browser — no login prompt, no download step. The page runs inside a sandboxed iframe so artifact scripts can't reach your Exulu session. Every other file type (Word, Excel, PDF, …) triggers an automatic download with the correct filename.

For public links, the unguessable share name is the entire access token — there are no shared secrets or service-to-service credentials in the URL. Password links store the credential in an httpOnly cookie and send it as an x-share-password header — never in the URL or page HTML.

REST API — create a share link
curl -X POST https://api.exulu.app/shared-artifacts \
  -H "Authorization: Bearer $TOKEN" \
  -d '{
    "s3key":     "uploads/q4-report.html",
    "name":      "q4-report",
    "auth_mode": "public",
    "expires_at": "2026-08-01T00:00:00Z"
  }'
# → { "name": "q4-report" }
# Shareable at: /artifacts/q4-report
