What's new in Exulu.

Speak instead of type. Speech-to-text now lives next to the send button in every chat — record, review, send.

Speech-to-text in chat

Talk to your agent — we'll type it for you.

A new mic button sits next to the chat send button. Click it to record, click again to stop. The clip is transcribed by Whisper and appended to whatever you've already typed — no autosend, you stay in control and press send when the wording is right.

Built on the same LiteLLM proxy that runs the rest of the platform. Whisper auto-detects the language; an optional language hint helps short clips. The 25 MB cap covers about 25 minutes of audio, far more than any single chat utterance.

From the API
# POST a recording, get text back
curl -X POST "$EXULU_BACKEND/transcribe" \
  -H "Authorization: Bearer $TOKEN" \
  -F "file=@recording.webm" \
  -F "language=en"

# → { "text": "What's the status of the Q4 launch?" }
Available when EXULU_USE_LITELLM=true and TRANSCRIPTION_MODEL is set. The mic button hides itself when the feature isn't enabled on a deployment.
